## Current status

Updated 2026-09-11. `MVP-Checklist.md` stays the source of truth; this is the short version.

- **Phases 0 to 12 are done** except T7.6, which is deferred with its reason in the checklist. Milestone B (slice mode) is reached with the fake agent. Nothing is published yet. CI runs everything on Ubuntu, Windows, and macOS.
- **Works today:** `scan` maps C# with Roslyn and TypeScript with the compiler API, then builds one slice per entry point (controller actions, `Map*` handlers, background services, Next.js pages) holding every function on its call path, an orphan unit for unreached functions, and whole-file units for everything else. `scan --mode file` keeps the Milestone A behavior. Every recorded finding gets a verify unit that asks a fresh call to refute it (D27, D29); `"verify": false` in config turns that off, `verify` runs only those units, and `report` leaves refuted findings out unless `--include-refuted` is given. `doctor` runs git and both mappers for real and prints the fix for each problem. `--version` prints the bare version.
- **Distribution (D33):** the release workflow publishes a self-contained folder build per platform as `@codemuster/<platform>-<arch>` plus the `codemuster` npm launcher, smoke-tests them through `npm install -g` on Windows, Linux, and macOS, and on a `v*` tag attaches the tgz files to a GitHub release. The launcher runs the newest build it finds and updates itself in the background at most once a day, never under `CI` or `CODEMUSTER_NO_UPDATE`. Run it by hand with `gh workflow run release.yml -f version=<x.y.z-dev.n>` to build and smoke-test without a release.
- **Try it before a release:** `dotnet publish src/CodeMuster.Cli -c Release -o <folder>`, put that folder on PATH, restore the target repo (`dotnet restore`, `npm ci`), then `codemuster init --yes`, `doctor`, `scan`, `run --agent claude -j 4`, and `report --out audit.md`.
- **Known gaps:** nothing limits a run to one subtree, which T13.3 needs; slice mode and verify have not run with a real agent; `estimate` cannot count verify calls before findings exist; the `codex`, `gemini`, and `opencode` adapters have never launched their harness; entry points miss Razor Pages, Blazor, SignalR, gRPC, minimal API lambdas, and actions inherited from a base controller; the win-arm64, linux-arm64, and osx-x64 builds are built but never smoke-tested; installed skill copies do not change when the CLI updates (L11).
