## Current status

- **Released:** `codemuster@0.3.5` (tag `v0.3.5`, commit `cfb0aa9`) and the six `@codemuster/*` platform packages are on npm, published by `release.yml` through trusted publishing. `CHANGELOG.md` has every release since 0.2.8. CI runs the full suite on hosted Ubuntu, Windows, and macOS runners, and `main` requires all three.
- **0.3.6 is prepared, not released:** branch `release/0.3.6` on GitHub holds the thirteen review fixes (EXEC1, SNAP1, TSAPI1, HASH1, VERIFY1, FIX3 to FIX5, AUDIT1, AUDIT2, PERF1, PERF2, USAGE1), 33 follow-ups from a review of those changes, and REL036 (CHANGELOG 0.3.6, plugin manifests). It passed the test workflow on Linux, Windows, and macOS (1,547 .NET and 72 npm tests on each, zero skips) and a `release.yml` dry run that built all six platforms and passed the installed-package smoke on win-x64, linux-x64, and darwin-arm64. Local `main` matches it; `origin/main` is still at 0.3.5.
- **Open checklist items:** T7.6, T13.3, T13.4, T13.6 to T13.8, T13.10 to T13.12, L1 to L7 and L10 to L16, and LIVE1 (`[~]`), each with its reason in the checklist.
- **Audit loop:** `scan` maps C# with Roslyn and TypeScript with the compiler API, builds one slice per entry point plus orphan and whole-file units, and audits dependency manifests with npm, pnpm, yarn, or `dotnet list package` on every scan (D38). `run` analyzes pending units, and every finding gets a verify unit (D27, D29, D34). Non-code files are excluded from AI review, and oversized packs are skipped with a reason (D49, D50). `"exclude"` in config and `--path` scope the work. `--model` and `--effort` pass through, and the ledger records provenance (D35). Dirty files are hashed as git would stage them (D57).
- **Fix mode:** `fix --agent <agent> [-j N]` repairs one file per worker in isolated worktrees, commits each repair that passes `test_command`, and records every finding Fixed or Declined (D37, D40, D46). It offers to stash local changes (D39), skips oversized files (D56), and drains instead of cancelling when one repair cannot be integrated (FIX2). From 0.3.6 it checks `test_command` on the unmodified tree before any agent call (`--allow-failing-tests` skips that) and never records Fixed without a changed file. `validate` runs the final build and test command. Fix has run with real models on this repository (the 30 `fix <path>` commits in REL032) and on ToolbagCRM.
- **Setup and agents:** `init` creates the config and installs project skills and change hooks (D42). `intelligent-config` makes one AI call to suggest exclusions, lenses, and a test command (D53). The plugin and skill follow `automation` in config (D47), the skill installs the CLI when it is missing (D44), and one marketplace plugin serves Claude and Codex (D45). `dead_code` and `user_experience` reviews are opt-in (D48).
- **Terminal:** agent commands show a banner and preview the provider, model, thinking level, and workers, with a 10 s countdown (D52, D54, D55). Run progress is colored. From 0.3.6 argument mistakes name the problem. `status`, `doctor`, `scan`, `estimate`, and `report` are still plain text.
- **Product value review (2026-09-25):** `docs/product-value-review.md` covers bugs, CLI look and feel, setup, performance, security, and features for `v0.3.5`: 143 confirmed defects (11 high), 8 design questions, about 90 improvement proposals, a Top 12, and suggested releases. Top 12 items 1 to 5, parts of 7 and 9 (TypeScript 7, compiled globs), and the usage errors of 11 are in 0.3.6; the rest are not tasks yet.
