## Current status

Updated 2026-09-11. `MVP-Checklist.md` stays the source of truth; this is the short version.

- **Phases 0 to 12 are done** except T7.6, which is deferred with its reason in the checklist, and so are T10.3, T10.4, T11.3, and T13.0. Milestone B (slice mode) is reached with the fake agent and with Claude Code. Nothing is published yet. CI runs everything on Ubuntu, Windows, and macOS.
- **Works today:** `scan` maps C# with Roslyn and TypeScript with the compiler API, then builds one slice per entry point (controller actions, `Map*` handlers, background services, Next.js pages) holding every function on its call path, an orphan unit for unreached functions, and whole-file units for everything else. `scan --mode file` keeps the Milestone A behavior. Every recorded finding gets a verify unit that asks a fresh call to refute it (D27, D29), and a defect in code nothing can reach is refuted (D34); `"verify": false` in config turns that off, `verify` runs only those units, and `report` leaves refuted findings out unless `--include-refuted` is given. `"exclude": ["folder/**"]` in config leaves files out of `scan` and `doctor`, which is how a first pass covers one part of a large repository. `doctor` runs git and both mappers for real and prints the fix for each problem. `doctor` and `scan` print progress on stderr as they work, each line with the elapsed seconds. `--version` prints the bare version.
- **Real runs (2026-09-11, Claude Code 2.1.268, restored fixture copies):** `run --agent claude -j 4` completed 37/37 units (18 analysis, 19 verify) on the first attempt in 9 min 17 s; both planted defects were found and confirmed, and verify refuted 5 of 19 findings with sound reasons. Driven only by the installed skill and the npm-installed package, Claude Code audited all 32 units of a second copy in 9 min 18 s, found and confirmed both planted defects, and left the repository unchanged.
- **Distribution (D33):** the release workflow publishes a self-contained folder build per platform as `@codemuster/<platform>-<arch>` plus the `codemuster` npm launcher, smoke-tests them through `npm install -g` on Windows, Linux, and macOS, and on a `v*` tag attaches the tgz files to a GitHub release. The launcher runs the newest build it finds and updates itself in the background at most once a day, never under `CI` or `CODEMUSTER_NO_UPDATE`. Run it by hand with `gh workflow run release.yml -f version=<x.y.z-dev.n>` to build and smoke-test without a release.
