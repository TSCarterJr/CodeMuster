claude-documented-two-models.json, claude-documented-error-max-turns.json, claude-documented-api-error.json
  Types SDKResultSuccess, SDKResultError and ModelUsage in @anthropic-ai/claude-agent-sdk@0.3.283
  (claudeCodeVersion 2.1.283): https://unpkg.com/@anthropic-ai/claude-agent-sdk@0.3.283/sdk.d.ts
  https://code.claude.com/docs/en/headless and https://code.claude.com/docs/en/agent-sdk/cost-tracking
  modelUsage covers every model call (subagents and helpers included); input excludes cache reads and writes.
  An error subtype (error_max_turns and similar) has no result field, only errors[]; an API error is
  subtype success with is_error true and the message in result. The exact nonzero exit code is not verified.
